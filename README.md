# 🚀 Interverse — Real-Time Coding Interview Platform

Interverse is a full-stack platform for conducting **real-time 1-on-1 technical interviews**, combining live video, chat, and a collaborative coding environment — all inside a single browser experience.

Built to simulate **FAANG-style coding interviews**, not just practice problems.

---

## ✨ Key Features

- 🔴 **Real-Time 1-on-1 Interview Rooms**
  - Secure rooms limited to **exactly two participants**
  - Live video, audio, chat, screen sharing & recording

- 💻 **Collaborative Code Editor**
  - VSCode-like in-browser editor
  - Multi-language support
  - Real-time code synchronization

- 🧪 **Code Execution & Evaluation**
  - Secure server-side code execution
  - Automated test case validation
  - Instant feedback during interviews

- 📚 **Interview Practice Mode**
  - Curated DSA problems (Easy / Medium)
  - Problem descriptions, examples & constraints
  - Seamless transition from practice → live interview

- 🔐 **Authentication & Access Control**
  - Clerk-based authentication
  - Interview rooms accessible only via secure session links

---

## 🛠 Tech Stack

**Frontend**
- React
- Tailwind CSS
- TanStack Query

**Backend**
- Node.js
- Express.js
- MongoDB

**Real-Time Infrastructure**
- Stream API (video calls, chat, screen sharing, recording)
- WebSockets for real-time collaboration

**Auth & Background Jobs**
- Clerk (authentication)
- Inngest (async workflows & background jobs)
